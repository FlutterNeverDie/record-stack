# 📑 [오늘의 기록] 제품 요구 사양서 (PRD)

## 1. 프로젝트 개요
- **서비스 명**: 오늘의 기록 (Today’s Record)
- **목적**: 사용자가 오늘 하루의 순간들을 사진으로 찍어 시간순으로 나열하고, 이를 하나의 감성적인 세로형 이미지로 만들어 소장할 수 있게 돕는 모바일 전용 웹 도구.
- **핵심 가치**: "기록하고, 내려받고, 끝낸다." (휘발성 및 개인정보 보호 강화)

## 2. UI/UX 원칙
- **Single Screen (No Scroll)**: 앱의 모든 인터페이스는 모바일 한 화면에 고정된다. 프레임이 늘어나도 스크롤 없이 전체 구조가 한눈에 들어와야 한다.
- **Mobile Optimized**: 모바일 브라우저 환경에 최적화된 터치 인터페이스와 레이아웃을 제공한다.
- **Clean Export**: 편집 중인 UI 요소(버튼, 아이콘, 제목)는 결과물 이미지에 포함하지 않는다.

## 3. 상세 기능 요구사항

### A. 메인 헤더 및 레이아웃
- **상단 정보**: 현재 날짜(YYYY.MM.DD)와 앱 타이틀 "오늘의 기록"을 표시한다.
- **가변 높이 스택**: 
  - 화면의 전체 높이에서 헤더와 버튼 영역을 제외한 나머지 공간을 프레임들이 나눠 갖는다.
  - 프레임 개수가 추가될 때마다 기존 프레임들의 높이는 자동으로 축소되며 화면 비율을 유지한다.

### B. 동적 프레임 생성 로직
- **초기 진입**: 중앙에 + 아이콘이 있는 빈 프레임 1개가 노출된다.
- **연쇄 생성**:
  1. 사용자가 빈 프레임의 + 버튼을 클릭하여 사진을 선택한다.
  2. 사진이 채워지면, 즉시 그 아래에 새로운 빈 프레임(+)이 생성된다.
  3. 최대 5개까지 사진 프레임을 쌓을 수 있다.

### C. 프레임 제어 기능
- **시간 선택 (Time Picker)**:
  - 각 사진 중앙에 위치한 시간을 터치하면 00:00 ~ 24:00 사이의 시간을 선택할 수 있는 휠(Wheel)이 나타난다.
  - 시간은 사용자가 직접 입력하는 것이 아니라 리스트에서 선택하는 방식이다.
- **상태 문구**: 시간 하단에 짧은 텍스트를 입력하거나 수정할 수 있다.
- **편집 및 삭제**:
  - 각 프레임 우측 상단에 수정 및 삭제 아이콘을 배치한다.
  - 삭제 시 해당 프레임은 사라지며, 화면 내 나머지 프레임들의 높이가 자동으로 재조정된다.
- **순서 변경 (Drag & Drop)**:
  - 프레임 영역을 꾹 누른 뒤 위아래로 움직여 사진의 순서를 자유롭게 바꿀 수 있다.

### D. 사진 다운로드 (Final Export)
- **데이터 처리**: 사용자가 올린 사진은 서버에 전송되거나 저장되지 않으며, 오직 브라우저 메모리 내에서만 처리된다.
- **결과물 구성**:
  - 편집 시 보였던 "오늘의 기록" 타이틀, + 빈 프레임, 수정/삭제/드래그 아이콘은 모두 제거한다.
  - 오직 사용자가 채운 사진 프레임들만 수직으로 이어 붙여진 이미지를 생성한다.
- **타임스탬프**: 이미지의 최하단 우측 끝에 작은 글씨로 해당 날짜(YYYY.MM.DD)를 표기한다.
- **종료**: 다운로드가 완료되면 모든 과정이 끝난다.

## 4. 세부 제어 규칙
- **비율 유지**: 사진은 각 프레임의 가로폭에 맞춰 꽉 차게(Center Crop) 배치되어야 한다.
- **화면 고정**: 프레임이 늘어나도 브라우저 자체 스크롤이 생기지 않도록 내부 컨테이너의 높이를 100%로 엄격히 제한한다.
- **이미지 품질**: 다운로드 시에는 화면에 보이는 저해상도 미리보기가 아닌, 원본 소스를 활용한 고화질 병합 이미지를 생성한다.
